# Krishikuta 🌾

Empowering Agriculture and Veterinary Aspirants with expert guidance, coaching, and professional consulting services.

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://krushikuta.vercel.app/)

## 🚀 Overview

Krishikuta is a comprehensive platform designed to support students and entrepreneurs in the agricultural and veterinary sectors. From competitive exam coaching to professional agricultural project reports, we provide the tools and expertise needed to succeed in the modern agri-landscape.

### 🔗 Live Website
Visit the live platform at: [https://krushikuta.vercel.app/](https://krushikuta.vercel.app/)

---

## ✨ Key Features

### 🎓 Educational Coaching
- **Agriculture Practical Exam Coaching**: Expert guidance for practical examinations.
- **AO / AAO / Bank Exam Prep**: Comprehensive preparation for Agriculture Officer and banking entrance exams.
- **ICAR Exam Prep**: Structured coaching for ICAR JRF/SRF and postgraduate entrance exams.

### 🏛️ Admission Guidance
- **VCI Veterinary Admission**: Assistance and counseling support for VCI quota seats.
- **K-CET Seat Allocation**: Complete support for the K-CET seat allotment process.
- **NRI Quota Admission**: Guidance for NRI quota admissions in veterinary and farm science courses.

### 💼 Professional Consulting
- **Agri Consulting (DPR)**: Bank-ready Detailed Project Reports (DPR) for:
  - Dairy Farming
  - Poultry Farming
  - Sheep & Goat Units
- **Technical Support**: Polyhouse setup, hydroponics, and crop loan assistance.
- **Startup & Investment**: Business model consulting and ROI projections for agri-investments.

## 🏗️ Getting Started

### Prerequisites
- Node.js (Latest LTS version recommended)
- npm or bun

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/rahul200618/krushikuta-main.git
   ```
2. Navigate to the project directory:
   ```bash
   cd krushikuta-main
   ```
3. Install dependencies:
   ```bash
   npm install
   # or
   bun install
   ```

### Environment Setup
Create a `.env` file in the root directory and add your Supabase credentials (refer to `.env.example`):
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Development
Start the development server:
```bash
npm run dev
```

### Production Build
Generate a production-ready build:
```bash
npm run build
```

## 📁 Project Structure

- `src/components`: Reusable UI components (Shadcn + custom).
- `src/routes`: Route definitions using TanStack Router.
- `src/lib`: Utility functions, site data, and Supabase client configuration.
- `src/hooks`: Custom React hooks for state and data fetching.
- `public`: Static assets (images, icons, robots.txt).
- `api`: Serverless functions/API routes.
